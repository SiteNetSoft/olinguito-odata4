# Tier 7 Wave 1 — URI Parser Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the OData URI parser accept every 4.01 spelling required by [OData-Protocol] §13.2.1 items 6, 7, 9a, 9b, 9c and 9j, without changing the meaning of a single URL that parses today.

**Architecture:** Parsing lives in `lib/server-core` with its enums in `lib/server-api`; evaluation lives in `lib/server-tecsvc` and is Wave 2's problem. Every change here is additive: a new spelling is accepted *after* the existing strict alternatives have been tried, so no currently-valid URL changes meaning and no currently-invalid URL becomes valid except the ones the spec names.

**Tech Stack:** Java 17, Maven, JUnit 5 (Jupiter 5.11.4), Mockito 5.21.0. Tests run per-module with `mvn test -Dtest=ClassName -pl <module>`.

**Spec:** `docs/superpowers/specs/2026-08-21-tier7-design.md` (citations: `docs/superpowers/specs/2026-08-21-tier7-citations.md`)

## Global Constraints

- **Additive, never substitutive.** Every strict 4.0 spelling (`$filter`, `duration'…'`, `Ns.Type'Yellow'`, `FnImport()`, `div`) must keep parsing exactly as it does today. Each task that adds a spelling also pins the old one.
- **Unconditional.** No relaxation may be gated on `OData-MaxVersion`. §13.2.1 item 9: *"MUST support both 4.0 and 4.01 syntax in URLs for supported functionality regardless of requested OData-MaxVersion"*.
- **`UriTokenizer.nextConstant` (line 740) must stay case-sensitive.** Only its four operator-facing callers change. Making the shared helper ignore case would make `NULL`, `Nan` and `INF` variants valid literals and would break §13.2.1 item 8 (identifiers returned in their declared case).
- **`divby` must be tried before `div`** in the tokenizer's alternatives, or `divby` lexes as `div` followed by a stray `by`.
- **License header:** when modifying a file, add a SiteNetSoft copyright line before the closing `*/` of the Apache block: ` * Copyright 2026 SiteNetSoft - <description of changes>`.
- **No AI attribution** in commit messages — no `Co-Authored-By`, no "Generated with".
- **Gate before declaring the wave done:** plain `mvn -B install --fail-at-end` (never `-Pbuild.fast`, which skips checkstyle/RAT/PMD).

## Design correction carried into this plan

The design document lists "the parsing halves of 9j and 9k" in Wave 1. **Item 9k has no parsing half** —
`substring(Name,-3)` already parses today (unary minus on an integer literal), and the clamp that violates the
spec is at `MethodCallOperator:151` in tecsvc. Item 9k is therefore entirely Wave 2. Wave 1 carries 9j's parse
half only.

```java
  /**
   * Reinterprets a single-quoted string literal against the type it is being applied to,
   * implementing [OData-Protocol] 13.2.1 items 9a (casting strings to primitive types in URLs)
   * and 9b (enumeration and duration literals without the type prefix). A literal that is
   * already in the form the expected type accepts is returned unchanged.
   */
  protected static String reinterpretQuotedLiteral(final String literal, final EdmType expectedType) {
    if (expectedType == null
        || literal == null
        || literal.length() < 2
        || !(literal.startsWith("'") && literal.endsWith("'"))) {
      return literal;
    }
    if (expectedType.getKind() == EdmTypeKind.ENUM) {
      // 'Yellow' -> Namespace.EnumType'Yellow'
      return expectedType.getFullQualifiedName().getFullQualifiedNameAsString() + literal;
    }
    final EdmPrimitiveType primitiveType = expectedType instanceof EdmTypeDefinition typeDef ?
        typeDef.getUnderlyingType() :
        (EdmPrimitiveType) expectedType;
    if (primitiveType.equals(odata.createPrimitiveTypeInstance(EdmPrimitiveTypeKind.String))) {
      return literal;
    }
    if (primitiveType.equals(odata.createPrimitiveTypeInstance(EdmPrimitiveTypeKind.Duration))) {
      // 'P12D' -> duration'P12D'
      return "duration" + literal;
    }
    // Every other primitive type takes its literal unquoted; the value itself is
    // validated by the caller's fromUriLiteral/validate pair, so a non-literal
    // string still fails there exactly as it does today.
    return literal.substring(1, literal.length() - 1).replace("''", "'");
  }
```

Add the imports the file does not already have: `EdmType`, `EdmTypeKind`, `EdmTypeDefinition`.
