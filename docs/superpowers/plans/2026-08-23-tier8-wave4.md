**Goal:** Add the `$compute` system query option end to end — [OData-Protocol] §13.2.2 item 8 — then re-audit §13.2.2 and §13.1.2 clause by clause and record the OData 4.01 Intermediate level as reached.

**Architecture:** `$compute` reuses the expression machinery `$apply` already has (`ComputeExpression`, `DynamicProperty`, `DynamicStructuredType`) and adds what a *system query option* needs: its own option type, a parser, wiring that runs before the options which consume its aliases, an evaluator that attaches results as dynamic properties, and a serializer that will write those properties on a closed type.

**Tech Stack:** Java 17, Maven, JUnit 5 in `lib/**`, JUnit 4 via the vintage engine in `fit/`.

**Spec:** `docs/superpowers/specs/2026-08-22-tier8-design.md` (citations: `docs/superpowers/specs/2026-08-22-tier8-citations.md`)

## Global Constraints

- **`$compute` runs before `$select`, `$filter` and `$orderby`.** [OData-Protocol] §11.2.5.3: computed properties "can be used in a $select or within a $filter or $orderby expression", so they must exist before those are parsed and evaluated. The ordering is an inference from that dependency, not a rule the spec states (design D5, citations G2).
- **A computed alias may not collide with a declared property** — 400 (design D3). `ApplyParser.parseAsAlias` already enforces this via `UriParserSemanticException.MessageKeys.IS_PROPERTY`; reuse that behavior rather than inventing another.
- **Computed properties are dynamic properties in the result.** §11.2.5.3: they "SHOULD be included as dynamic properties in the result and MUST be included if $select is specified with the computed property name, or star (*)".
- **Never mutate a shared `Property` or `Entity`.** The copies upstream are shallow — see Wave 3's `SelectOptionsHandler` and the comment in `TechnicalEntityProcessor` — so an evaluator must add to a copied entity, never to the one the data provider holds.
- **`$apply` keeps answering 501.** Reusing its parse layer implies nothing about aggregation support.
- **License header:** add a SiteNetSoft line before the closing `*/`: ` * Copyright 2026 SiteNetSoft - <description of changes>`.
- **No AI attribution** in commit messages.

```java
/**
 * Parses the $compute system query option ([OData-Protocol] 11.2.5.3, [OData-ABNF] rule compute):
 * a comma-separated list of <code>commonExpr "as" odataIdentifier</code>.
 * <p>
 * Each alias is added to the referenced type as a dynamic property, which is what lets $select,
 * $filter and $orderby name it afterwards -- so this parser must run before those are parsed.
 */
public class ComputeParser {

  private final Edm edm;
  private final OData odata;

  public ComputeParser(final Edm edm, final OData odata) {
    this.edm = edm;
    this.odata = odata;
  }

  public ComputeOption parse(UriTokenizer tokenizer, final EdmStructuredType referencedType,
      final Map<String, AliasQueryOption> aliases) throws UriParserException, UriValidationException {
    final ComputeOptionImpl option = new ComputeOptionImpl();
    do {
      final Expression expression = new ExpressionParser(edm, odata)
          .parse(tokenizer, referencedType, null, aliases);
      final EdmType expressionType = ExpressionParser.getType(expression);
      if (expressionType == null || expressionType.getKind() != EdmTypeKind.PRIMITIVE) {
        throw new UriParserSemanticException("Compute expressions must return primitive values.",
            UriParserSemanticException.MessageKeys.ONLY_FOR_PRIMITIVE_TYPES, "compute");
      }
      ParserHelper.requireNext(tokenizer, TokenKind.AsOperator);
      ParserHelper.requireNext(tokenizer, TokenKind.ODataIdentifier);
      final String alias = tokenizer.getText();
      if (referencedType instanceof DynamicStructuredType dynamicType) {
        if (dynamicType.hasStaticProperty(alias)) {
          throw new UriParserSemanticException("Alias '" + alias + "' is already a property.",
              UriParserSemanticException.MessageKeys.IS_PROPERTY, alias);
        }
        dynamicType.addProperty(new DynamicProperty(alias, expressionType));
      }
      option.add(new ComputeExpressionImpl().setExpression(expression).setAlias(alias));
    } while (tokenizer.next(TokenKind.COMMA));
    return option;
  }
}
```

Check `TokenKind.AsOperator` exists — `ApplyParser.parseAsAlias` uses `tokenizer.next(TokenKind.AsOperator)`, so it does; `requireNext` turns its absence into the SYNTAX error the test expects.

```java
      final Map<String, AliasQueryOption> aliases) throws UriParserException, UriValidationException {
    if (option != null) {
      final String optionValue = option.getText();
      UriTokenizer tokenizer = new UriTokenizer(optionValue);
      ((ComputeOptionImpl) option).getExpressions().clear();
      for (final ComputeExpression expression : new ComputeParser(edm, odata)
          .parse(tokenizer, contextType instanceof EdmStructuredType structuredType ? structuredType : null,
              aliases).getExpressions()) {
        ((ComputeOptionImpl) option).add(expression);
      }
      checkOptionEOF(tokenizer, option.getName(), optionValue);
    }
  }
```

```java
/**
 * Evaluates the $compute system query option and attaches each result to the entity as a dynamic
 * property named by its alias ([OData-Protocol] 11.2.5.3: computed properties "SHOULD be included
 * as dynamic properties in the result").
 */
public final class ComputeHandler {

  private ComputeHandler() {
    // Utility class, mirroring the other handlers in this package.
  }

  public static void applyCompute(final ComputeOption computeOption,
      final EntityCollection entityCollection, final Edm edm) throws ODataApplicationException {
    if (computeOption == null || entityCollection == null) {
      return;
    }
    for (final Entity entity : entityCollection.getEntities()) {
      applyCompute(computeOption, entity, edm);
    }
  }

  public static void applyCompute(final ComputeOption computeOption, final Entity entity, final Edm edm)
      throws ODataApplicationException {
    if (computeOption == null || entity == null) {
      return;
    }
    for (final ComputeExpression computeExpression : computeOption.getExpressions()) {
      final VisitorOperand operand;
      try {
        operand = computeExpression.getExpression()
            .accept(new ExpressionVisitorImpl(entity, null, edm));
      } catch (final ExpressionVisitException e) {
        throw new ODataApplicationException("Error computing " + computeExpression.getAlias(),
            HttpStatusCode.INTERNAL_SERVER_ERROR.getStatusCode(), Locale.ROOT, e);
      }
      final TypedOperand typed = operand.asTypedOperand();
      // The alias cannot collide with a declared property -- the parser rejects that -- so an
      // existing property of this name is a value computed for an earlier entity of a shared
      // instance, which must never happen; replace rather than append so a repeat is harmless.
      entity.getProperties().removeIf(property -> computeExpression.getAlias().equals(property.getName()));
      entity.addProperty(new Property(null, computeExpression.getAlias(),
          ValueType.PRIMITIVE, typed.getValue()));
    }
  }
}
```

In `ODataJsonSerializer.writeDynamicProperties`, replace the early return with a check that also admits computed properties:

```java
  private void writeDynamicProperties(final ServiceMetadata metadata, final EdmStructuredType type,
      final List<Property> properties, final Set<String> selected, final boolean all,
      final Set<String> computedNames, final JsonGenerator json)
      throws IOException, SerializerException {
    if (!type.isOpenType() && computedNames.isEmpty()) {
      return;
    }
    final Set<String> declaredNames = new HashSet<>(type.getPropertyNames());
    final Set<String> navigationNames = new HashSet<>(type.getNavigationPropertyNames());
    for (final Property property : properties) {
      final String name = property.getName();
      if (declaredNames.contains(name) || navigationNames.contains(name)) {
        continue;
      }
      // A closed type has no dynamic properties of its own; only a computed one may appear
      // ([OData-Protocol] 11.2.5.3), so on such a type nothing else is written.
      if (!type.isOpenType() && !computedNames.contains(name)) {

      }
    }
  }
```

```java
  private Set<String> computedPropertyNames(final ComputeOption compute) {
    if (compute == null) {

      names.add(expression.getAlias());
    }

```
